**English**

**What:** We built the Digital Public Authority Assistant — a Rust/Axum API for GDPR redaction, statutory deadlines, and VAT/register validation, plus a React portal.
**Why:** Because the law fixes the answer — one day off or one leaked number is a real failure — so the system computes exactly and stays auditable.
**How:** Pure, well-tested domain services behind a thin HTTP layer, with Postgres audit hashing, Redis caching/rate limiting, Docker Compose, and 69 tests plus 55 `api.http` checks.

**Deutsch**

**Was:** Wir haben den Digitalen Behörden-Assistenten gebaut — eine Rust/Axum-API für DSGVO-Schwärzung, Fristen und USt-/Registerprüfung, plus ein React-Portal.
**Warum:** Weil das Gesetz die Antwort vorgibt — ein Tag zu viel oder eine geleakte Nummer ist ein echter Fehler — also rechnet das System exakt und bleibt auditierbar.
**Wie:** Reine, gut getestete Domänen-Services hinter einer schlanken HTTP-Schicht, mit Postgres-Audit-Hashing, Redis-Cache/Rate-Limiting, Docker Compose und 69 Tests sowie 55 `api.http`-Checks.
